# H 策略 v2.1 — 規格說明書

最後更新: 2026-04-21

---

## 1. 定位與目標

- **標的**: 00631L（元大台灣50正2 ETF）
- **操作模式**: 主倉全進全出，搭配每年定期加碼
- **核心思想**: 用四個市場災難指標判斷「現在是否危險」，危險時出場持現金，安全時全倉持有

## 3. 四個災難條件（C1~C4）

每日計算以下四個條件，**當日命中數 = n**：

| 條件 | 指標 | 觸發邏輯 |
|---|---|---|
| **C1** | 0050 均線 | 0050 收盤 < MA60 **且** < MA120 |
| **C2** | VIX 三線 | VIX > 28 **且** VIX9D > 28 **且** VIX3M > 28 |
| **C3** | 00631L 回撤 | 00631L 收盤較歷史高點回撤 > 10% |
| **C4** | SMH 均線 | SMH 收盤 < MA30 **且** < MA60 |

**`disaster = (n >= 3)`**（四個中至少三個同時命中）

---

## 4. 出場邏輯（漸進門檻 / whipsaw 防護 E）

### 核心機制

```
sell_threshold = 2 + sell_streak
```

- 第一次出場：需連續 **2** 個 disaster 日
- 第二次出場：需連續 **3** 個 disaster 日
- 第三次出場：需連續 **4** 個 disaster 日
- 依此類推，每次出場門檻 +1

### sell_streak 重置條件

持倉期間，連續 **30 個交易日** n < 3（非 disaster）→ `sell_streak` 歸零

### 執行

觸發當日標記 `pending = SELL`，**隔日（T+1）以開盤價出場**。

---

## 5. 回場邏輯（三選一，任一滿足即回場）

| 條件 | 說明 |
|---|---|
| **A 原版回場** | 當日 n < 3（非 disaster） |
| **B 急漲回場** | 當日收盤較前日上漲 ≥ 8% |
| **C 反彈回場** | 從出場後的最低點反彈 ≥ 20% |

觸發當日標記 `pending = BUY`，**隔日（T+1）以開盤價買入**。

---

## 6. 加碼機制

- 每年 1 月 1 日後第一個交易日，自動補入 50 萬
- 若持倉中，以當日收盤價直接加購股票
- 若空倉，現金留存待下次回場一起投入
