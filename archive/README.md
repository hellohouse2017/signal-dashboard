## grid_backtest.py / grid_variant_research.py — 網格策略

**結論：所有變體都打不過 Buy & Hold。**

20 組參數（fixed / reset_3x / ma20 / ma20_regime60 × step 3~8%）× 2019-2025：
- **beat B&H 的年數：全部 1/7**
- 平均超額報酬 vs B&H：**全部為負**（-22% ~ -46%）

**關鍵教訓**：
1. 槓桿 ETF 長期趨勢向上，網格的「高賣低買」在單邊行情裡系統性踏空。
2. 回測用「猜測的日內 OHLC 路徑」（漲日 open→low→high→close），**系統性高估成交次數與獲利**，連這種樂觀假設都打不過 B&H，實盤只會更差。
3. 20 組參數 × 7 年、無樣本外分割 = 典型參數挖礦。這正是 v2.2 優化時刻意避開的陷阱。

## 真實 1分K 日內當沖 — 體檢否決（2026-07-07）

**結論：00631L 日內是「成本 > 訊號」市場，當沖負期望。這次用真實 1分K，不是猜路徑。**

先前歸檔的當沖用日線模擬（粒度不足）。這次改用 `scanner/intraday.db` 真實 1分K
（00631L，2026-04-10→07-07，32 交易日，8406 根）做純描述性體檢，無參數擬合：

| 事實 | 數據 | 對當沖的意義 |
|---|---|---|
| 隔夜 vs 日內波動 | 隔夜跳空 std **8.82%** vs 日內 open→close std **2.33%** | 報酬 3.8 倍集中在隔夜；當沖收盤平倉＝放棄主要波動來源 |
| 1分K 自相關 | lag1 +0.098（bid-ask bounce 假象）、lag2 −0.04、lag5≈0 | 無穩定可交易動量 |
| 大波動後下根 5分K 條件報酬 | 大漲後 +0.010% / 大跌後 +0.008% / 平盤 −0.005% | 全在雜訊內，且 < round-trip 成本 0.24% |
| 進場時點（買方） | 首30分均價 vs 開盤 +0.086% ± SE 0.183%（\|t\|=0.47） | 開盤價非系統性差點；「等 X 分鐘再進」無顯著 edge |
| 唯一真結構 | 波動集中開盤（09:00-09:30 16.4bps/min → 尾盤 5bps） | 幅度仍 < 成本，且開盤方向樣本 n=19/13 過小 |

**關鍵教訓（延續前面第 3 點）**：
1. 換真實 1分K 把「猜路徑」的美化拿掉後，連虛假獲利都不剩 → 印證日線當沖的正期望是假象。
2. 1分K 窗口僅 3 個月（yfinance 硬限制），樣本量問題比日線更嚴重，無法區分 edge 與擬合。
3. 「用日內數據優化 v2.2 進出場」同樣驗不了：v2.2 約每年 3 次交易（11 年 32 賣），3 個月窗口內幾乎沒有 v2.2 實際交易可校準。
4. 體檢腳本：`/tmp/intraday_health.py` + `/tmp/exec_timing.py`（一次性，未入庫）。

## 真正有 edge 的是什麼？

主策略 **H v2.2**（`scanner/h_strategy.py` canonical + `scanner/h_v2_2.py` 引擎）。
它的 alpha 來源是**災難避開**（2022 -7% vs B&H -36%），不是選股訊號。
全期（2015-2026，美股 as-of 對齊後引擎）CAGR 47.0% / MDD -32.5%，
vs B&H 35.9% / -55.1%——報酬更高、回撤減半，但 alpha 集中在 4 個災難事件，
數字當區間看（45~48%），詳見 `state.md` 2026-07-27 體檢。
